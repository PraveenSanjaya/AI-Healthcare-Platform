# Decisions

Log of choices made where the spec was ambiguous or a version conflict forced a change.

| # | Date | Decision | Reason |
|---|------|----------|--------|
| 1 | 2026-11-04 | Docker and WSL were not available on the machine used for Phase 1, so `docker compose up`, `prisma migrate dev` and the first migration file were NOT run. DB steps are documented in the README only. | Environment limitation. Must be verified in WSL2 + Docker Desktop before relying on the schema; the initial migration is generated by the first `npx prisma migrate dev`. |
| 2 | 2026-11-04 | `@types/node` bumped from `^20` to `^22`. | `vitest` 5 declares a peer dependency on `@types/node` `^22 \|\| >=24`; the Next.js scaffold pinned 20, causing an ERESOLVE failure. Node 22 is the runtime in use. |
| 3 | 2026-11-04 | Prisma 7 with the `prisma-client` generator (output `lib/generated/prisma`) and the `@prisma/adapter-pg` driver adapter. The datasource URL lives in `prisma.config.ts`, not in `schema.prisma`. | Prisma 7 requires a driver adapter and moved connection config out of the schema. The generated client is git-ignored and rebuilt by `prisma generate`. |
| 4 | 2026-11-04 | `.env.example` is explicitly un-ignored (`!.env.example`). | The default `.env*` rule in the Next.js `.gitignore` would otherwise hide it. |
| 5 | 2026-11-04 | Adminer is under a Compose profile (`tools`) so it only starts with `docker compose --profile tools up -d`. | Spec calls it optional. |
| 6 | 2026-11-04 | Repository moved out of OneDrive to `C:\dev\AI-Healthcare-Platform`. | OneDrive syncing of `node_modules`/`.next` causes slowness and file-lock errors. |
| 7 | 2026-11-04 | Phase 2 uses Auth.js v5 (`next-auth@5.0.0-beta.32`) with the Credentials provider and JWT sessions; bcryptjs (cost 12) for hashing. | Credentials login requires JWT sessions, so the Auth.js adapter tables (Account/Session/VerificationToken) are not needed and were not added. |
| 8 | 2026-11-04 | Route protection lives in `proxy.ts` (Next 16 rename of `middleware`), delegating to the pure `decideAccess` in `lib/auth/route-access.ts`. Server code must still call `requireRole` (defence in depth). | Proxy is not a sufficient sole authorisation layer; pure function keeps it unit-testable. |
| 9 | 2026-11-04 | **Migrations are pending.** No database is available yet, so `prisma migrate dev` has not been run and no migration exists. Phase 2 DB-touching code (`auth.ts`, login action) is typechecked but untested end to end. Run `npx prisma migrate dev --name init` once a database is available, then seed an admin. | Environment limitation; supersedes the migration note in #1 for hosted DBs. |
| 10 | 2026-11-04 | Decision #6 is reversed: the project stays in the OneDrive folder; there is a single copy. | Owner's instruction. |
